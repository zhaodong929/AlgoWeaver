# 移动平均算法

## 问题定义
移动平均算法用于对时间序列进行平滑，降低短期随机波动对趋势观察的影响。

## 输入与输出
- 输入：按时间顺序排列的一维数值序列 data。
- 参数：窗口大小 window，必须为正整数，且不能超过输入序列长度。
- 输出：长度为 len(data) - window + 1 的移动平均序列。

## 算法步骤
1. 按时间顺序读取输入序列。
2. 使用长度为 window 的滑动窗口遍历数据。
3. 计算每个窗口内数值的算术平均值。
4. 按窗口移动顺序输出平均值序列。

## 边界与失败情况
- 输入序列为空时无法计算。
- window 小于等于 0 时参数无效。
- window 大于输入序列长度时无法产生输出。

## 可用验证指标
- 与参考实现逐元素比较结果。
- 记录运行时间和内存使用量。
