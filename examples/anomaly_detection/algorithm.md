# 设备传感器异常检测（Z-score 基线）

## 业务场景

对生产设备的温度或压力时间序列进行快速巡检，标记明显偏离历史分布的读数，
供运维人员复核。该示例使用一个小型、可复现的项目内 CSV fixture；生产环境应
替换为经过授权的业务数据或开放许可数据。

## 输入与输出

- 输入：按时间排序的传感器数值序列 `values`。
- 参数：异常阈值 `threshold`，默认 2.0 个标准差。
- 输出：每个样本的 z-score 和 `is_anomaly` 标记。

## 算法步骤

1. 检查输入序列非空，并计算均值和总体标准差。
2. 对每个读数计算 `abs(value - mean) / std`。
3. 当 z-score 大于阈值时标记为异常。
4. 将样本索引、原始值、z-score 和标记写入结果。

## 验证要求

- 对包含一个明显尖峰的 fixture 检查尖峰被标记。
- 对空序列、单样本、常数序列和非法阈值执行边界测试。
- 记录异常数量、运行时间和输入来源。
